# Sistema de Gestão de Alunos e Professores

Este repositório contém uma atividade desenvolvida durante o curso de Análise e Desenvolvimento de Sistemas, com foco no desenvolvimento de uma aplicação integrada a uma API.

O sistema permite consultar, cadastrar, editar e excluir registros de alunos e professores, além de oferecer recursos de busca, filtros, estatísticas e paginação.

## Tecnologias utilizadas

* JavaScript
* C#
* HTML
* CSS
* Docker
* Font Awesome

## Funcionalidades

* Cadastro de alunos e professores
* Edição e exclusão de registros
* Consulta de dados através da API
* Busca por nome, e-mail ou telefone
* Filtros por tipo de usuário
* Dashboard com estatísticas
* Paginação
